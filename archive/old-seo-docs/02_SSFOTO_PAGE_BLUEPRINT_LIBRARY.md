SSFOTO_PAGE_BLUEPRINT_LIBRARY.md

Dokumen ini berisi template standar untuk setiap jenis halaman di website SS Foto.

Tujuan dokumen ini:

menjaga konsistensi struktur halaman

mempercepat produksi konten SEO

memudahkan validasi oleh Gemini

memastikan internal linking selalu benar

Semua halaman baru harus mengikuti blueprint ini.

7. INTERNAL LINKING RULES

Setiap halaman harus memiliki minimal:

3 internal link.

Contoh:

Pas Foto Page:

/pas-foto
→ /cetak-foto
→ /lokasi

Cetak Foto Page:

/cetak-foto
→ /cetak-foto-4r
→ /cetak-canvas
8. CTA RULE

Setiap halaman harus memiliki CTA.

Contoh:

Upload Foto
Ambil Pas Foto
Hubungi Toko
9. CONTENT QUALITY RULE

Konten harus:

mudah dibaca

fokus pada layanan

tidak terlalu teknis fotografi

menyebut lokasi

10. OUTPUT FORMAT UNTUK CLAUDE

Meta description
