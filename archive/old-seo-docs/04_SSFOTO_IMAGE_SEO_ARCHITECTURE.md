SSFOTO_IMAGE_SEO_ARCHITECTURE.md
1. Objective

Dokumen ini mendefinisikan sistem pengelolaan gambar pada website SS Foto agar:

meningkatkan visibilitas di Google Image Search

memperkuat entity SEO

meningkatkan engagement pengguna

Setiap gambar yang diunggah ke website harus mengikuti standar ini.

2. Image SEO Principles

Gambar harus membantu Google memahami:

service
entity
context

Setiap gambar harus terkait dengan layanan SS Foto seperti:

pas foto
cetak foto
canvas printing
studio foto

Gambar tidak boleh generik.

3. File Naming Convention

Nama file harus deskriptif dan mengandung keyword.

Contoh yang benar:

pas-foto-3x4-ssfoto.jpg
cetak-foto-4r-printing.jpg
canvas-foto-keluarga.jpg
studio-foto-keluarga-rawamangun.jpg

Contoh yang salah:

IMG_1023.jpg
photo1.jpg
image-final.jpg

Gunakan format:

service-keyword-location.jpg
4. Alt Text Rules

Alt text harus:

menjelaskan gambar

mengandung keyword

natural

Contoh alt text:

Pas foto ukuran 3x4 di SS Foto Rawamangun
Cetak foto ukuran 4R dengan kualitas lab profesional
Canvas foto keluarga hasil cetak SS Foto

Alt text membantu Google memahami isi gambar.

5. Image Caption

Caption sangat membantu SEO.

Contoh caption:

Contoh hasil cetak foto ukuran 4R di SS Foto
Pas foto resmi untuk dokumen administrasi
Canvas foto keluarga untuk dekorasi rumah

Caption tidak boleh kosong.

6. Image Size Optimization

Gambar harus dioptimasi agar website tetap cepat.

Standar ukuran:

Hero image: 1200px – 1600px
Content image: 800px – 1200px
Thumbnail: 400px – 600px

Format file yang direkomendasikan:

WebP

Ini membantu Core Web Vitals.

7. Image Context Placement

Google memahami gambar berdasarkan konteks di halaman.

Setiap gambar harus berada dekat dengan teks yang relevan.

Contoh:

Halaman:

/pas-foto

Gambar harus berupa:

contoh pas foto
proses pengambilan foto
hasil cetak pas foto

Bukan gambar random.

8. Image Internal Relevance

Gambar juga harus mendukung entity.

Contoh pada halaman:

/cetak-foto-4r

Gunakan gambar:

hasil cetak foto 4R
proses printing foto

Ini membantu Google memahami halaman tersebut.

9. Gallery Strategy

Halaman tertentu harus memiliki gallery.

Contoh:

Studio Foto
hasil foto keluarga
hasil foto prewedding
studio setup
Canvas Printing
canvas foto keluarga
canvas dekorasi rumah
canvas portrait

Gallery meningkatkan engagement.

10. Image Structured Data

Beberapa halaman harus memiliki schema markup untuk gambar.

Contoh:

ImageObject
Product
LocalBusiness

Ini membantu Google menampilkan gambar di rich results.

11. Image Sitemap

Website harus memiliki image sitemap.

Contoh:

/sitemap-images.xml

Sitemap ini membantu Google menemukan semua gambar di website.

12. Image Publishing Rules

Setiap halaman layanan minimal memiliki:

3 – 5 gambar

Ideal:

5 – 8 gambar

Gambar harus:

relevan

unik

berkualitas tinggi

13. Image Content Sources

Gambar yang digunakan harus berasal dari:

hasil cetak SS Foto
hasil studio SS Foto
foto proses produksi

Hindari menggunakan stock photos berlebihan.

Google lebih menyukai gambar asli.

14. Image Engagement Strategy

Beberapa gambar harus mendorong interaksi.

Contoh:

before / after printing
studio setup
hasil canvas di rumah

Ini meningkatkan waktu kunjungan.

15. Image SEO Checklist

Sebelum gambar diunggah ke website, pastikan:

nama file mengandung keyword
alt text ada
caption ada
ukuran file optimal
gambar relevan dengan halaman

Jika salah satu tidak terpenuhi, gambar harus diperbaiki.

17. Strategic Advantage

Website SS Foto memiliki potensi besar di Google Image Search karena:

layanan berbasis visual

banyak contoh hasil cetak

banyak hasil studio foto

Jika image SEO diterapkan dengan benar, website dapat memperoleh traffic dari:

Google Images

yang sering kali diabaikan oleh kompetitor.
