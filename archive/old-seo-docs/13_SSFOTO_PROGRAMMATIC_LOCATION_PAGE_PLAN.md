SSFOTO_PROGRAMMATIC_LOCATION_PAGE_PLAN.md
1. Objective

Dokumen ini mendefinisikan sistem pembuatan programmatic location pages untuk website SS Foto.

Tujuan utama:

menangkap traffic pencarian berbasis lokasi

memperluas jangkauan SEO secara sistematis

memperkuat local authority SS Foto

Model ini memungkinkan website memiliki puluhan hingga ratusan halaman SEO lokal tanpa mengorbankan kualitas struktur.

2. Programmatic SEO Principle

Programmatic SEO pada proyek SS Foto mengikuti prinsip berikut:

service + location

Contoh query yang ditargetkan:

pas foto rawamangun
pas foto bekasi
cetak foto bekasi
studio foto keluarga jakarta timur

Halaman dibuat untuk menangkap query tersebut.

3. Core Services Used for Programmatic Pages

Tidak semua layanan digunakan untuk programmatic SEO.

Hanya layanan utama yang digunakan:

pas foto
cetak foto
studio foto keluarga

Alasan:

volume pencarian tinggi

intent transaksi jelas

mudah dikaitkan dengan lokasi

4. URL Structure

Semua halaman programmatic menggunakan struktur berikut:

/service-location

Contoh:

/pas-foto-rawamangun
/pas-foto-bekasi
/cetak-foto-bekasi
/studio-foto-keluarga-bekasi

Struktur ini membantu Google memahami:

service
+
location

6. Page Generation Model

Halaman programmatic menggunakan template yang sama.

Contoh struktur halaman:

Section 1 — Hero

Judul:

Pas Foto di Bekasi

Subheadline:

Layanan pas foto profesional dengan hasil cetak berkualitas lab.
Section 2 — Service Description

Menjelaskan:

layanan yang tersedia

proses layanan

kualitas cetak

Section 3 — Location Context

Menjelaskan:

area yang dilayani

jarak ke toko SS Foto

lokasi cabang terdekat

Section 4 — Gallery

Menampilkan contoh:

hasil pas foto

hasil cetak foto

Section 5 — FAQ

Contoh:

Apakah bisa pas foto tanpa reservasi?
Berapa lama proses pas foto?
7. Internal Linking Rules

Halaman programmatic harus memiliki link berikut.

Contoh:

/pas-foto-bekasi

Internal link:

→ /pas-foto
→ /lokasi
→ /cetak-foto

Ini membantu distribusi authority.

8. Duplicate Content Prevention

Halaman programmatic tidak boleh sepenuhnya identik.

Variasi konten harus mencakup:

nama kota
area sekitar
jarak ke toko
transportasi

Ini membantu mencegah duplicate content.

9. Scaling Strategy

Halaman baru dibuat berdasarkan prioritas berikut:

search demand
population density
distance to existing stores

Kota besar dibuat lebih dahulu.

10. Page Publishing Strategy

Untuk fase awal, halaman dapat dipublish secara burst publishing.

Contoh:

20 halaman sekaligus

Ini membantu Google memahami cluster topik.

11. Integration With Local SEO

Halaman programmatic harus terhubung dengan:

/lokasi
Google Maps listing

Ini membantu memperkuat sinyal SEO lokal.
