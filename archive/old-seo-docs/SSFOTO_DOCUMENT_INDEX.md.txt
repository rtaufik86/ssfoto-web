1. Document Purpose

Dokumen ini berfungsi sebagai index dan hierarchy untuk seluruh dokumen SEO dalam proyek SS Foto.

Tujuan:

memberikan panduan navigasi dokumen

menentukan dokumen mana yang authoritative

menghindari konflik instruksi antar dokumen

membantu LLM dan developer memahami sistem

Semua model AI dan developer harus membaca dokumen ini terlebih dahulu sebelum menggunakan dokumen lain.

2. Document Classification System

Dokumen dalam proyek dibagi menjadi tiga kategori:

CORE DOCUMENTS

Dokumen inti yang menentukan strategi SEO utama.

Karakteristik:

authoritative
strategic
tidak boleh diubah tanpa approval

Dokumen ini menjadi referensi utama untuk:

GPT
Claude
Gemini
Developer
SYSTEM DOCUMENTS

Dokumen operasional yang menjelaskan implementasi teknis.

Karakteristik:

digunakan oleh developer
menjelaskan struktur dan implementasi
tidak mengubah strategi utama
REFERENCE DOCUMENTS

Dokumen tambahan yang berisi penjelasan detail atau konteks tambahan.

Karakteristik:

informational
tidak authoritative
digunakan sebagai referensi
